## 🚀 第一章：极速启动指南 (开机必读)

本项目依赖 DeepSeek/Qwen 等大模型进行最终的润色，但核心数据完全由本地 Python 脚本实时算力生成。

### 1. 启动步骤

由于服务器重启或环境重置，建议每次开机按以下顺序操作：

**步骤一：进入项目目录**
打开终端 (Terminal)，输入：
```bash
cd /home/kk/n8n
```

**步骤二：管理持仓 (可选)**
如果您有新的持仓需要监控，请编辑 `my_stocks.txt`：
```bash
nano my_stocks.txt
# 每行输入一个股票代码（6位数字），如 600519
# 按 Ctrl+O 保存，Enter 确认，Ctrl+X 退出
```

**步骤三：启动 N8N (工作流引擎)**
本项目的工作流运行在 N8N 上。建议使用 Docker 启动（如果已配置）或直接运行：
```bash
# 假设您已配置好 N8N 环境
n8n start
# 或者如果是 docker 环境: docker start n8n
```
*注：保持此终端窗口开启，或将其挂起后台。*

**步骤四：手动触发 (测试用)**
如果您不想等定时任务，想立刻看盘，可以在另一个终端运行：
```bash
# 运行脚本生成数据 (带 std-json 参数以适配 N8N)
python3 market_scanner.py --std-json
```
如果看到 JSON 输出，说明数据源正常。此时去 N8N 界面点击 "Execute Workflow" 即可收到飞书/微信推送。

## ❓ 第二章：常见问题与急救箱 (Troubleshooting)

### Q1: N8N 报错 "JSON parameter needs to be valid JSON"
**原因**：Python 脚本输出了多余的 print 日志（如“正在扫描...”），弄脏了 JSON 数据流。
**解决**：
1. 确保 N8N "Execute Command" 节点中的命令必须包含 `--std-json` 参数。
   ```bash
   python3 /home/kk/n8n/market_scanner.py --std-json
   ```
2. 检查 `market_scanner.py` 中是否意外引入了没被劫持的 `print` 语句（本项目已做 `sys.stderr` 重定向处理）。

### Q2: 报告里看不到“持仓哨兵”板块
**原因**：
1. `my_stocks.txt` 文件不存在或为空。
2. 您的持仓在这个交易日没有任何数据更新（如停牌）。
**解决**：检查 `/home/kk/n8n/my_stocks.txt` 内容，确保全是 6 位数字代码，且每行一个。

### Q3: 报告提示“数据只是普通文本，没有评级”
**原因**：Python 脚本运行失败，N8N 的 `zhantie.txt` (Code节点) 触发了 JS 兜底逻辑。
**解决**：
1. 在终端运行 `python3 market_scanner.py` 看是否有报错。
2. 常见原因是网络超时（新浪/东财接口波动），等待 1 分钟重试通常能解决。

### Q4: 评分全是 50 分，没有“妖股”
**原因**：行情过于平淡，或者盘中数据未更新（如休市期间）。
**解决**：这是真实的市场反应。系统只有在通过算法检测到“主升浪”特征（均线多头+放量+RSI适中）时才会给出高分。

## 🧠 第三章：项目架构与运作逻辑

### 3.1 核心运作流
1.  **数据采集 (The Eyes)**：
    *   **新浪财经 API**：实时毫秒级行情、龙虎榜数据（稳定、快速）。
    *   **AKShare**：获取历史K线数据，用于计算 MA、RSI 等技术指标。
    *   **同花顺**：资金流向与题材热度扫描。
2.  **量化清洗 (The Brain - Python)**：
    *   **0-100 评分系统**：基于 `trend_score`（趋势）、`vol_ratio`（量能）、`rsi`（超买超卖）的综合数学模型。
    *   **角色分配**：自动根据板块内的涨幅和封板情况，判定 👑龙一、⚔️龙二。
    *   **持仓巡检**：对 `my_stocks.txt` 中的标的进行独立体检，给出“高抛/低吸”建议。
3.  **智能分发 (The Mouth - N8N)**：
    *   Python 输出纯净 JSON -> N8N Code 节点 (适配器) -> LLM (DeepSeek/Qwen) 进行“游资风格”润色 -> 发送到 飞书/钉钉/微信。

### 3.2 项目特色
*   **游资审美**：不同于传统的“基本面研报”，本项目只关心**势**（Trend）和**量**（Volume）。
*   **反脆弱**：内置了多层兜底接口。新浪挂了切东财，东财挂了切静态列表，Python 挂了 JS 代码还能手搓简报。
*   **硬核评级**：
    *   ⭐⭐⭐⭐⭐ (妖股)：主升浪，缩量加速，持股者的盛宴。
    *   ⭐⭐⭐⭐ (强推)：放量突破，右侧交易的最佳买点。
    *   💀 (卖出)：高位巨量阴线或破位下跌。

### 3.3 技术栈一览
*   **后端**: Python 3.x, Pandas, AkShare, Requests (Chrome伪装)
*   **编排**: N8N (Node-based Workflow Automation)
*   **AI**: 兼容 OpenAI 格式的大模型接口 (Qwen-Max / DeepSeek-V3)
